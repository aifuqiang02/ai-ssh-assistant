## 🔄 数据流对比

### SSH 文件夹创建的数据流

#### 本地模式（Electron + SQLite）

```
用户点击 → 服务层 → IPC 调用 → 树服务 → 存储管理器 → SQLite
    ↓        ↓        ↓        ↓        ↓        ↓
AppSidebar → ssh.service → ssh-handlers → ssh-tree.service → storageManager → better-sqlite3
     ↓        ↓        ↓        ↓        ↓        ↓
createRootFolder() → SSHLocalImpl → 'ssh:create-folder' → createFolder() → create('SSHFolder') → INSERT
```

#### 远程模式（HTTP + PostgreSQL）

```
用户点击 → 服务层 → HTTP 请求 → API 路由 → 服务逻辑 → PostgreSQL
    ↓        ↓        ↓        ↓        ↓        ↓
AppSidebar → ssh.service → axios/fetch → /api/v1/ssh/folders → ssh.service → Prisma
     ↓        ↓        ↓        ↓        ↓        ↓
createRootFolder() → SSHApiImpl → POST /ssh/folders → fastify.post() → createFolder() → INSERT
```

## 🎯 关键设计点

1. **统一服务接口**：`sshService.createFolder()`
   方法在本地和远程模式下调用方式完全相同
2. **自动模式选择**：`createService()` 根据
   `localStorage.getItem('storageMode')` 自动选择实现
3. **用户 ID 处理**：
   - 本地模式：固定使用 `'local-user'`
   - 远程模式：从 JWT Token 中提取用户 ID
4. **分层架构**：页面 → 服务 → IPC/HTTP → 业务逻辑 → 数据库
5. **类型安全**：所有层级共享相同的 TypeScript 类型定义
6. **错误处理**：每层都有完善的错误处理和用户反馈

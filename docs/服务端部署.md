# AI SSH Assistant 服务端部署指南

本文档介绍如何部署 AI SSH Assistant 服务端。

## 📦 本地构建

### 自动化构建

使用提供的构建脚本：

```bash
# 克隆代码
git clone <repository-url>
cd ai-ssh-assistant

# 构建服务端（推荐）
./scripts/build-server.sh

# 选项
./scripts/build-server.sh --clean    # 强制清理
./scripts/build-server.sh --docker   # 同时构建 Docker 镜像
```

构建脚本会自动完成：
- 依赖安装和验证
- 类型检查（服务端包）
- 代码质量检查
- 测试运行
- 数据库客户端生成
- 按依赖顺序构建
- 生成生产部署包

### 构建产物

成功构建后会生成：
```
packages/server/dist-bundle/
├── index.js              # 打包后的应用代码
├── prisma/               # 数据库相关文件
└── package.json          # 包配置
```

**部署包**：将 `packages/server/dist-bundle/` 目录上传到服务器。

## ⚙️ 环境变量配置

在部署目录（`dist-bundle`）中创建 `.env` 文件：

```bash
# 必需环境变量
NODE_ENV=production
PORT=3000
DATABASE_URL=postgresql://user:pass@host:5432/db
CLOUD_DATABASE_URL=postgresql://user:pass@host:5432/db  # 种子数据使用
REDIS_HOST=redis-host
REDIS_PORT=6379
JWT_SECRET=your-64-char-jwt-secret
ENCRYPTION_KEY=your-32-char-encryption-key

# AI API 密钥（根据需要配置）
OPENAI_API_KEY=sk-your-openai-key
ANTHROPIC_API_KEY=sk-ant-your-anthropic-key
```

**完整变量列表**：参考源码中的环境变量文档。

## 🚀 部署执行

### 直接运行

```bash
# 上传构建产物到服务器
scp -r packages/server/dist-bundle/ user@server:/opt/ai-ssh/

# 在服务器上配置环境变量
cd /opt/ai-ssh/dist-bundle
# 在此目录创建 .env 文件

# 运行服务
node index.js
```

### 使用 PM2（推荐）

```bash
# 上传构建产物到服务器
scp -r packages/server/dist-bundle/ user@server:/opt/ai-ssh/

# 在服务器上配置环境变量
cd /opt/ai-ssh/dist-bundle
# 在此目录创建 .env 文件

# 安装 PM2 并启动服务
npm install -g pm2
pm2 start ecosystem.config.js
pm2 status
pm2 logs ai-ssh-server
```

### 使用 Docker

```bash
# 上传构建产物到服务器
scp -r packages/server/ user@server:/opt/ai-ssh/

# 在服务器上构建和运行
cd /opt/ai-ssh/packages/server
docker build -f Dockerfile -t ai-ssh-server .
docker run -d --name ai-ssh-server -p 3000:3000 --env-file .env ai-ssh-server
```

## 🔍 验证部署

```bash
# 健康检查
curl http://localhost:3000/health

# 查看日志
pm2 logs ai-ssh-server  # PM2
docker logs ai-ssh-server  # Docker
```

## 🗄️ 数据库设置

### 数据库初始化

**重要：** 需要在启动服务前手动初始化数据库。

```bash
# 1. 确保 PostgreSQL 和 Redis 服务运行
sudo systemctl start postgresql redis-server

# 2. 确保环境变量已设置（.env 文件）
# DATABASE_URL 和 CLOUD_DATABASE_URL 必须正确配置

# 3. 切换到部署目录
cd /opt/ai-ssh/dist-bundle

# 4. 运行数据库迁移（创建表结构）
npx prisma migrate deploy  # 自动读取 DATABASE_URL

# 5. 插入种子数据（创建初始用户和示例数据）
npx prisma db seed  # 读取 CLOUD_DATABASE_URL（未设置时使用默认值）

# 查看创建的测试账户
# 管理员: admin@ai-ssh-assistant.com / admin123
# 用户: user@ai-ssh-assistant.com / user123

# 注意：生产环境请删除或修改这些测试账户
```

**环境变量自动读取：**
- ✅ `npx prisma migrate deploy` - 自动读取 `DATABASE_URL`
- ✅ `npx prisma db seed` - 读取 `CLOUD_DATABASE_URL`（未设置时使用默认值）
- ✅ **服务器启动时不会自动运行迁移，需要手动执行**

**种子数据包含：**
- 管理员账户（admin@ai-ssh-assistant.com）
- 普通用户账户（user@ai-ssh-assistant.com）
- 示例聊天会话和欢迎消息

### 数据库管理

```bash
# 查看数据库结构
npx prisma studio

# 重置数据库（开发环境）
npx prisma migrate reset --force

# 生成客户端（如果需要）
npx prisma generate
```

## 🚨 故障排查

- 检查数据库连接：`psql -h host -U user -d db`
- 检查 Redis 连接：`redis-cli -h host ping`
- 查看端口占用：`netstat -tlnp | grep :3000`
- 检查数据库迁移状态：`npx prisma migrate status`
- 验证种子数据：`npx prisma studio`
- 检查日志获取详细错误信息

## 🎯 博客发布流程

### 1. 撰写博客

在对应分类目录下创建 Markdown 文件：

```bash
# 版本发布博客
docs/csdn-blog/releases/v{版本号}-{标题}.md

# 功能介绍博客
docs/csdn-blog/features/{功能名称}.md

# 使用教程博客
docs/csdn-blog/tutorials/{教程主题}.md
```

### 2. 博客模板

```markdown
# 标题

> 作者：AI SSH Assistant 开发团队  
> 日期：YYYY-MM-DD  
> 版本：vX.Y.Z（如果是版本发布）

## 📝 前言

...

## ✨ 功能亮点

...

## 🛠️ 技术实现

...

## 🎯 使用场景

...

## 📥 下载体验

...

## 🎉 总结

...

---

> 如果觉得本文对你有帮助，欢迎点赞、收藏、关注！  
> 有任何问题欢迎在评论区讨论～
```

### 3. 更新索引

在本 README 中添加博客链接和摘要。

### 4. 发布到 CSDN

1. 登录 CSDN
2. 创建新文章
3. 复制 Markdown 内容
4. 添加合适的标签
5. 选择分类（后端、前端、工具等）
6. 发布文章

### 5. 同步链接

在博客文件头部添加 CSDN 链接：

```markdown
> **CSDN 链接**: https://blog.csdn.net/xxx/article/details/xxxxx
```

## 📝 写作规范

### 标题规范
- 版本发布：`v{版本号} - {核心功能}`
- 功能介绍：`{功能名称}：{副标题}`
- 使用教程：`{主题} - {难度等级}`

### 标签规范
必选标签：
- `SSH` / `终端` / `Electron` / `Vue3` / `TypeScript`

可选标签：
- `AI` / `自动化` / `运维` / `开发工具` / `桌面应用`

### 内容规范
1. **前言**：介绍背景和痛点
2. **功能亮点**：列举核心特性
3. **技术实现**：详细技术方案
4. **使用场景**：实际应用案例
5. **下载体验**：提供下载链接
6. **总结**：归纳要点

### 代码规范
- 使用语法高亮
- 添加注释说明
- 提供完整示例
- 标注关键代码

### 图片规范
- 使用高清截图
- 添加清晰标注
- 控制图片大小
- 使用图床服务

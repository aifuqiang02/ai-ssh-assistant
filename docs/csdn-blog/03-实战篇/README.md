### 2. 《systemctl 命令挂起？巧用 --no-pager 避免交互式命令陷阱》

**关键词**：SSH、命令挂起、交互式命令

**内容大纲**：
```markdown
## 问题现象
- systemctl status 命令一直等待
- journalctl 查看日志卡住
- git log 无法返回

## 问题根源
- 这些命令默认使用 pager（less）
- 等待用户按 q 退出
- 在 SSH 自动化执行中会挂起

## 解决方案
- 添加 --no-pager 选项
- systemctl --no-pager status
- journalctl --no-pager -n 50
- git --no-pager log

## AI 系统提示词优化
- 教育 AI 主动使用 --no-pager
- System Prompt 中添加规则
- 常见命令列表

## 代码实现
- 自动添加 --no-pager 的逻辑
- 命令改写

## 其他交互式命令
- vim、nano 等编辑器
- 交互式安装程序
- 如何处理？

## 总结
- SSH 自动化的注意事项
- 交互式命令的陷阱
```

- 数据模型设计：connectionId 实现按连接隔离

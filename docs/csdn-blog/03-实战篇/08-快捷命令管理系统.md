# 实战篇08：打造终端快捷命令系统 - 让重复操作一键搞定

> 作者：AI SSH Assistant 开发团队

> 系列：AI SSH Assistant 开发实战

## 📖 开发故事

### 痛点发现

在开发 AI SSH Assistant 的过程中，我发现自己每天都在重复输入相同的命令：

```bash
# 查看日志
tail -f /var/log/nginx/error.log

# 重启服务
systemctl restart nginx

# 查看容器
docker ps -a | grep myapp
```

每次手动输入不仅浪费时间，还容易输错。特别是在管理多台服务器时，不同服务器的命令路径、参数都不一样，更容易混淆。

我想："能不能像浏览器收藏夹一样，把常用命令收藏起来，需要时一键执行？"

### 需求分析

经过一番思考，我列出了核心需求：

1. **一键收藏**：选中命令右键收藏，不打断工作流
2. **独立存储**：不同服务器的命令互不干扰
3. **智能搜索**：快速找到需要的命令
4. **使用统计**：常用命令自动排在前面
5. **完整编辑**：可以修改和完善命令
6. **导入导出**：方便备份和团队分享

## 🛠️ 技术实现过程

### 第一步：设计数据模型

首先定义快捷命令的数据结构：

```typescript
export interface ShortcutCommand {
  id: string              // 唯一标识
  command: string         // 命令内容
  description?: string    // 命令描述
  tags?: string[]        // 标签列表
  createdAt: number      // 创建时间
  usedCount: number      // 使用次数
  lastUsedAt?: number    // 最后使用时间
  connectionId?: string  // 所属连接ID（关键！）
}
```

最关键的是 `connectionId` 字段，用于实现按连接隔离存储。

### 第二步：实现服务层

创建 `ShortcutCommandService` 来管理所有操作：

```typescript
class ShortcutCommandService {
  private readonly STORAGE_KEY = 'terminal_shortcut_commands'

  // 按连接ID生成独立的存储键
  private getStorageKey(connectionId?: string): string {
    if (connectionId) {
      return `${this.STORAGE_KEY}_${connectionId}`
    }
    return this.STORAGE_KEY
  }

  // 获取指定连接的命令
  getAll(connectionId?: string): ShortcutCommand[] {
    const key = this.getStorageKey(connectionId)
    const data = localStorage.getItem(key)
    return data ? JSON.parse(data) : []
  }

  // 添加命令
  add(command: string, description?: string, 
      tags?: string[], connectionId?: string): ShortcutCommand {
    const commands = this.getAll(connectionId)
    
    // 检查重复
    const existing = commands.find(c => c.command === command)
    if (existing) return existing

    const newCommand: ShortcutCommand = {
      id: Date.now().toString() + Math.random().toString(36).substr(2, 9),
      command,
      description,
      tags,
      createdAt: Date.now(),
      usedCount: 0,
      connectionId
    }

    commands.push(newCommand)
    this.save(commands, connectionId)
    return newCommand
  }

  // 记录使用情况
  recordUsage(id: string, connectionId?: string): void {
    const commands = this.getAll(connectionId)
    const command = commands.find(c => c.id === id)
    
    if (!command) return

    command.usedCount++
    command.lastUsedAt = Date.now()
    this.save(commands, connectionId)
  }
}
```

**关键设计**：
- 使用 `connectionId` 生成独立的存储键
- 每个 SSH 连接的数据完全隔离
- 自动记录使用频率，便于排序

### 第三步：Vue 组件开发

创建 `ShortcutCommandsModal.vue` 管理界面：

```vue
<template>
  <Teleport to="body">
    <div v-if="visible" class="modal-wrapper">
      <div class="modal-content">
        <!-- 搜索栏 -->
        <div class="search-bar">
          <i class="bi bi-search"></i>
          <input 
            v-model="searchKeyword" 
            placeholder="搜索命令..."
            class="search-input"
          />
        </div>

        <!-- 统计和排序 -->
        <div class="stats-bar">
          <span>共 {{ filteredCommands.length }} 个命令</span>
          <div class="sort-options">
            <button 
              :class="{ active: sortBy === 'frequency' }"
              @click="sortBy = 'frequency'"
            >
              使用频率
            </button>
            <button 
              :class="{ active: sortBy === 'time' }"
              @click="sortBy = 'time'"
            >
              创建时间
            </button>
          </div>
        </div>

        <!-- 命令列表 -->
        <div class="commands-list">
          <div 
            v-for="cmd in filteredCommands" 
            :key="cmd.id"
            class="command-item"
            @click="handleUseCommand(cmd)"
          >
            <div class="command-info">
              <code>{{ cmd.command }}</code>
              <span v-if="cmd.usedCount > 0" class="usage-badge">
                使用 {{ cmd.usedCount }} 次
              </span>
            </div>
            <div class="command-actions">
              <button @click.stop="handleEdit(cmd)">编辑</button>
              <button @click.stop="handleDelete(cmd)">删除</button>
            </div>
          </div>
        </div>
      </div>
    </div>
  </Teleport>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'
import { shortcutCommandService } from '@/services/shortcut-command.service'

const props = defineProps<{
  visible: boolean
  connectionId?: string  // 当前连接ID
}>()

// 加载命令（自动按连接过滤）
const loadCommands = () => {
  commands.value = shortcutCommandService.getAll(props.connectionId)
}

// 搜索和过滤
const filteredCommands = computed(() => {
  let list = commands.value
  
  if (searchKeyword.value) {
    list = shortcutCommandService.search(
      searchKeyword.value, 
      props.connectionId
    )
  }
  
  // 排序
  return sortBy.value === 'frequency'
    ? list.sort((a, b) => b.usedCount - a.usedCount)
    : list.sort((a, b) => b.createdAt - a.createdAt)
})

// 使用命令
const handleUseCommand = (cmd: ShortcutCommand) => {
  // 记录使用
  shortcutCommandService.recordUsage(cmd.id, props.connectionId)
  // 执行命令
  emit('use-command', cmd.command)
  emit('close')
}
</script>
```

**关键技术点**：

1. **Vue 3 Teleport**：将弹窗渲染到 body 根节点，解决 z-index 层级问题
2. **计算属性缓存**：`filteredCommands` 只在依赖变化时重新计算
3. **按连接过滤**：所有操作都传递 `connectionId`

### 第四步：终端集成

在 `TerminalView.vue` 中集成：

```vue
<template>
  <!-- 右键菜单 -->
  <div class="context-menu">
    <div 
      v-if="hasSelection" 
      @click="handleAddShortcutCommand"
    >
      <i class="bi bi-lightning-charge"></i>
      收藏为快捷命令
    </div>
    <div @click="handleShowShortcutCommands">
      <i class="bi bi-lightning"></i>
      快捷命令
    </div>
  </div>

  <!-- 快捷命令弹窗 -->
  <ShortcutCommandsModal
    :visible="showShortcutCommands"
    :connection-id="currentConnectionId"
    @close="showShortcutCommands = false"
    @use-command="handleUseShortcutCommand"
  />
</template>

<script setup lang="ts">
// 收藏命令
const handleAddShortcutCommand = () => {
  const selection = terminal.value?.getSelection()
  if (!selection) return
  
  const command = selection.trim()
  
  // 关联到当前连接
  shortcutCommandService.add(
    command, 
    undefined, 
    undefined, 
    currentConnectionId.value
  )
  
  console.log('✅ 已收藏命令:', command)
}

// 使用命令
const handleUseShortcutCommand = async (command: string) => {
  if (!currentConnectionId.value) return
  
  // 直接发送命令到 SSH
  await window.electronAPI.ssh.write(
    currentConnectionId.value, 
    command + '\r'
  )
}
</script>
```

## 🐛 踩坑记录

### 坑1：弹窗被遮挡

**问题**：使用 `position: fixed` 的弹窗被父元素遮挡

**原因**：父元素设置了 `position: relative` 和 `z-index`，影响了 fixed 定位

**解决方案**：使用 Vue 3 的 `Teleport` 组件

```vue
<Teleport to="body">
  <!-- 弹窗内容 -->
</Teleport>
```

`Teleport` 将组件渲染到 DOM 的其他位置，但保持逻辑关系不变。

### 坑2：命令执行后重复

**问题**：选择完整命令（如 `cd /var/www`）后，终端显示 `cd cd /var/www`

**原因**：只删除了当前 token，没有删除整行

**解决方案**：区分完整命令和补全片段

```typescript
async function selectSuggestion(suggestion: Suggestion) {
  // 判断是否为完整命令
  const isCompleteCommand = suggestion.type === 'special' &&
    (suggestion.icon === '🤖' || suggestion.icon === '🕐')

  let deleteCount = currentContext.value.currentToken.length

  // 完整命令：删除整行
  if (isCompleteCommand) {
    deleteCount = currentContext.value.currentLine.length
  }

  // 发送退格键删除
  for (let i = 0; i < deleteCount; i++) {
    await window.electronAPI.ssh.write(connectionId, '\x7F')
  }

  // 插入新命令
  await window.electronAPI.ssh.write(connectionId, insertValue)
  
  // 完整命令自动执行
  if (isCompleteCommand) {
    await window.electronAPI.ssh.write(connectionId, '\r')
  }
}
```

### 坑3：不同服务器命令混淆

**问题**：在服务器 A 收藏的命令，在服务器 B 也显示

**原因**：所有命令存储在同一个 localStorage 键下

**解决方案**：按 `connectionId` 分区存储

```typescript
// 服务器 A 的存储键
localStorage.getItem('terminal_shortcut_commands_ssh-server-a')

// 服务器 B 的存储键
localStorage.getItem('terminal_shortcut_commands_ssh-server-b')
```

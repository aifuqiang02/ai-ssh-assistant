# 数据库设计：从本地 SQLite 到云端 PostgreSQL

数据库设计是应用的基础。AI SSH Assistant 支持两种存储模式：

- 🏠 **本地模式** - 使用 SQLite，数据存储在本地
- ☁️ **云端模式** - 使用 PostgreSQL，数据同步到云端

本文将详细讲解：

- 📊 数据库选型
- 🛠️ Prisma ORM
- 📋 表结构设计
- 🔄 双存储模式

## 数据库选型

### 本地模式：SQLite

**为什么选择 SQLite？**

**优势**：

- ✅ 无需安装服务器
- ✅ 零配置
- ✅ 单文件存储
- ✅ 跨平台
- ✅ 性能优秀（本地访问）
- ✅ 可靠性高

**劣势**：

- ❌ 不支持并发写入
- ❌ 不支持网络访问
- ❌ 功能相对简单

**适用场景**：

- 个人使用
- 桌面应用
- 离线应用
- 轻量级应用

### 云端模式：PostgreSQL

**为什么选择 PostgreSQL？**

**优势**：

- ✅ 功能强大
- ✅ 支持并发
- ✅ 支持复杂查询
- ✅ 支持 JSON 类型
- ✅ 扩展性好
- ✅ 社区活跃

**劣势**：

- ❌ 需要服务器
- ❌ 配置复杂
- ❌ 资源占用高

**适用场景**：

- 多用户应用
- 云端服务
- 数据同步
- 企业应用

### 统一的数据访问接口

```typescript
// database/src/repository/base.repository.ts
export abstract class BaseRepository<T> {
  abstract findById(id: string): Promise<T | null>
  abstract findAll(): Promise<T[]>
  abstract create(data: Partial<T>): Promise<T>
  abstract update(id: string, data: Partial<T>): Promise<T>
  abstract delete(id: string): Promise<void>
}

// database/src/repository/ssh.repository.ts
export class SSHRepository extends BaseRepository<SSHConnection> {
  constructor(private prisma: PrismaClient) {
    super()
  }

  async findById(id: string): Promise<SSHConnection | null> {
    return this.prisma.sSHConnection.findUnique({
      where: { id },
      include: {
        folder: true
      }
    })
  }

  async findByUserId(userId: string): Promise<SSHConnection[]> {
    return this.prisma.sSHConnection.findMany({
      where: { userId },
      include: {
        folder: true
      },
      orderBy: {
        createdAt: 'desc'
      }
    })
  }

  async create(data: Partial<SSHConnection>): Promise<SSHConnection> {
    return this.prisma.sSHConnection.create({
      data: data as any
    })
  }

  async update(
    id: string,
    data: Partial<SSHConnection>
  ): Promise<SSHConnection> {
    return this.prisma.sSHConnection.update({
      where: { id },
      data: data as any
    })
  }

  async delete(id: string): Promise<void> {
    await this.prisma.sSHConnection.delete({
      where: { id }
    })
  }
}
```

### 数据同步策略

```typescript
// database/src/sync/sync-manager.ts
export class SyncManager {
  constructor(
    private localPrisma: PrismaClient,
    private cloudPrisma: PrismaClient
  ) {}

  /**
   * 同步本地数据到云端
   */
  async syncToCloud(userId: string): Promise<void> {
    // 1. 获取本地数据
    const localConnections = await this.localPrisma.sSHConnection.findMany({
      where: { userId }
    })

    // 2. 批量上传到云端
    for (const conn of localConnections) {
      await this.cloudPrisma.sSHConnection.upsert({
        where: { id: conn.id },
        create: conn,
        update: conn
      })
    }
  }

  /**
   * 从云端同步数据到本地
   */
  async syncFromCloud(userId: string): Promise<void> {
    // 1. 获取云端数据
    const cloudConnections = await this.cloudPrisma.sSHConnection.findMany({
      where: { userId }
    })

    // 2. 批量下载到本地
    for (const conn of cloudConnections) {
      await this.localPrisma.sSHConnection.upsert({
        where: { id: conn.id },
        create: conn,
        update: conn
      })
    }
  }

  /**
   * 双向同步（合并策略）
   */
  async bidirectionalSync(userId: string): Promise<void> {
    const localData = await this.localPrisma.sSHConnection.findMany({
      where: { userId }
    })

    const cloudData = await this.cloudPrisma.sSHConnection.findMany({
      where: { userId }
    })

    // 合并数据（以最新的为准）
    const merged = this.mergeData(localData, cloudData)

    // 更新本地和云端
    for (const item of merged) {
      await Promise.all([
        this.localPrisma.sSHConnection.upsert({
          where: { id: item.id },
          create: item,
          update: item
        }),
        this.cloudPrisma.sSHConnection.upsert({
          where: { id: item.id },
          create: item,
          update: item
        })
      ])
    }
  }

  private mergeData(local: any[], cloud: any[]): any[] {
    const map = new Map()

    // 添加本地数据
    local.forEach(item => map.set(item.id, item))

    // 合并云端数据（以更新时间为准）
    cloud.forEach(item => {
      const existing = map.get(item.id)
      if (!existing || item.updatedAt > existing.updatedAt) {
        map.set(item.id, item)
      }
    })

    return Array.from(map.values())
  }
}
```

## 数据安全

### SSH 密码加密

```typescript
// database/src/crypto/encryption.ts
import crypto from 'crypto'

export class EncryptionService {
  private algorithm = 'aes-256-cbc'
  private key: Buffer

  constructor(secretKey: string) {
    // 生成 32 字节的密钥
    this.key = crypto.scryptSync(secretKey, 'salt', 32)
  }

  /**
   * 加密
   */
  encrypt(text: string): string {
    const iv = crypto.randomBytes(16)
    const cipher = crypto.createCipheriv(this.algorithm, this.key, iv)

    let encrypted = cipher.update(text, 'utf8', 'hex')
    encrypted += cipher.final('hex')

    return iv.toString('hex') + ':' + encrypted
  }

  /**
   * 解密
   */
  decrypt(encrypted: string): string {
    const parts = encrypted.split(':')
    const iv = Buffer.from(parts[0], 'hex')
    const encryptedText = parts[1]

    const decipher = crypto.createDecipheriv(this.algorithm, this.key, iv)

    let decrypted = decipher.update(encryptedText, 'hex', 'utf8')
    decrypted += decipher.final('utf8')

    return decrypted
  }
}

// 使用
const encryption = new EncryptionService(process.env.ENCRYPTION_KEY!)

// 保存时加密
const encryptedPassword = encryption.encrypt(password)
await prisma.sSHConnection.create({
  data: {
    ...data,
    password: encryptedPassword
  }
})

// 读取时解密
const connection = await prisma.sSHConnection.findUnique({ where: { id } })
const decryptedPassword = encryption.decrypt(connection.password!)
```

### 用户密码哈希

```typescript
// database/src/crypto/password.ts
import bcrypt from 'bcrypt'

export class PasswordService {
  private saltRounds = 10

  /**
   * 哈希密码
   */
  async hash(password: string): Promise<string> {
    return bcrypt.hash(password, this.saltRounds)
  }

  /**
   * 验证密码
   */
  async verify(password: string, hash: string): Promise<boolean> {
    return bcrypt.compare(password, hash)
  }
}

// 使用
const passwordService = new PasswordService()

// 注册时
const hashedPassword = await passwordService.hash(password)
await prisma.user.create({
  data: {
    email,
    password: hashedPassword
  }
})

// 登录时
const user = await prisma.user.findUnique({ where: { email } })
const isValid = await passwordService.verify(password, user.password)
```

## 完整示例

```typescript
// database/src/repositories/ssh-connection.repository.ts
import { PrismaClient, SSHConnection } from '@prisma/client'
import { EncryptionService } from '../crypto/encryption'

export class SSHConnectionRepository {
  private encryption: EncryptionService

  constructor(
    private prisma: PrismaClient,
    encryptionKey: string
  ) {
    this.encryption = new EncryptionService(encryptionKey)
  }

  /**
   * 创建连接
   */
  async create(data: {
    name: string
    host: string
    port: number
    username: string
    authType: 'password' | 'privateKey'
    password?: string
    privateKey?: string
    passphrase?: string
    folderId?: string
    userId: string
  }): Promise<SSHConnection> {
    // 加密敏感信息
    const encrypted = {
      ...data,
      password: data.password ? this.encryption.encrypt(data.password) : null,
      privateKey: data.privateKey
        ? this.encryption.encrypt(data.privateKey)
        : null,
      passphrase: data.passphrase
        ? this.encryption.encrypt(data.passphrase)
        : null
    }

    return this.prisma.sSHConnection.create({
      data: encrypted as any
    })
  }

  /**
   * 获取连接（解密）
   */
  async findById(id: string): Promise<SSHConnection | null> {
    const connection = await this.prisma.sSHConnection.findUnique({
      where: { id },
      include: {
        folder: true
      }
    })

    if (!connection) return null

    // 解密敏感信息
    return {
      ...connection,
      password: connection.password
        ? this.encryption.decrypt(connection.password)
        : null,
      privateKey: connection.privateKey
        ? this.encryption.decrypt(connection.privateKey)
        : null,
      passphrase: connection.passphrase
        ? this.encryption.decrypt(connection.passphrase)
        : null
    } as SSHConnection
  }

  /**
   * 获取用户的所有连接
   */
  async findByUserId(userId: string): Promise<SSHConnection[]> {
    const connections = await this.prisma.sSHConnection.findMany({
      where: { userId },
      include: {
        folder: true
      },
      orderBy: {
        createdAt: 'desc'
      }
    })

    // 批量解密
    return connections.map(conn => ({
      ...conn,
      password: conn.password ? this.encryption.decrypt(conn.password) : null,
      privateKey: conn.privateKey
        ? this.encryption.decrypt(conn.privateKey)
        : null,
      passphrase: conn.passphrase
        ? this.encryption.decrypt(conn.passphrase)
        : null
    })) as SSHConnection[]
  }

  /**
   * 更新连接
   */
  async update(
    id: string,
    data: Partial<SSHConnection>
  ): Promise<SSHConnection> {
    // 加密敏感信息
    const encrypted: any = { ...data }
    if (data.password)
      encrypted.password = this.encryption.encrypt(data.password)
    if (data.privateKey)
      encrypted.privateKey = this.encryption.encrypt(data.privateKey)
    if (data.passphrase)
      encrypted.passphrase = this.encryption.encrypt(data.passphrase)

    return this.prisma.sSHConnection.update({
      where: { id },
      data: encrypted
    })
  }

  /**
   * 删除连接
   */
  async delete(id: string): Promise<void> {
    await this.prisma.sSHConnection.delete({
      where: { id }
    })
  }
}
```

## 总结

数据库设计的关键要点：

1. **合理选型** - SQLite（本地）+ PostgreSQL（云端）
2. **使用 ORM** - Prisma 提供类型安全和开发效率
3. **双存储模式** - 支持本地和云端，灵活切换
4. **数据安全** - 加密敏感信息，哈希密码
